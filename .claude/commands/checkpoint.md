Revisar el estado actual del bootcamp y determinar en qué checkpoint está el equipo.

Pasos:
1. Ejecutar `npm run typecheck` — si falla, el trabajo es arreglar errores primero
2. Ejecutar `npm run verify` — identificar el primer checkpoint que falla
3. Listar exactamente qué falta para pasar ese checkpoint
4. Sugerir el siguiente paso concreto (qué archivo editar o qué comando ejecutar)

Ser específico: "Falta agregar X en src/tools/registry.ts línea Y" es más útil que "registra la herramienta".
